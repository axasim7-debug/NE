# Case Selection

## The only hard requirement
**A complete, officially released police footage archive exists for the case**
(bodycam / dashcam / 911 / interrogation published by the agency, prosecutor, court, or via public records).
Any crime type is fine: murder, robbery, chase, standoff, kidnapping, fraud, anything a police camera captured.

## Quick checks (not filters, just notes)
- Where is the footage published? (agency YouTube / website / records portal / court exhibits) + link
- How many hours / files? Enough for a 30–60 min video?
- Is the outcome known (verdict / plea / still pending)? If pending, we say "alleged".
